Tompouce

A terminal live-coding environment for music, inspired by Strudel, built in C.

Source Documentation Discussions

Install

Linux x86_64. The installer supports Arch/Omarchy, Debian/Ubuntu and Fedora. Run it as your user; it uses sudo only for distro packages.

git clone https://github.com/ekollof/tompouce.git
cd tompouce
./install.sh
~/.local/bin/tompouce

Add --no-browser for a terminal-only install. Sound banks are downloaded beside the binary and keep working offline.

First sound

Type this in the editor. Press F5 to evaluate. If transport is stopped, press Ctrl+P.

setcpm(108 / 4)
note("c4 e4 g4 c5").s('triangle').gain(0.4)

Press F2 and enter /tutor for 22 lessons. F1 is the keybinding reference.

In the terminal

  • Strudel patterns run in QuickJS. Audio is rendered in C.
  • Write, evaluate and listen in one keyboard-driven session, with vi editing.
  • Output goes through PipeWire, PulseAudio, JACK or ALSA.
  • A Chromium companion is optional. The engine keeps running natively.

Original project code is AGPL-3.0-or-later. Dependencies and sound banks keep their own licenses.
