Bakery

The public jam room server for Tompouce. Host a room, share an invite, play together — from two terminals anywhere on the internet.

End-to-end encrypted by default. No accounts, no passwords: whoever holds the invite link holds the key.

Start jamming Guides How encryption works

Start jamming in three steps

  • Install Tompouce (source). This server is already the default, so nothing needs configuring.
  • Pick a nickname. Press F2 and type /nick your-name. It is saved and reused in every room. Skip this and you get a generated one like amber-otter.
  • Host or join. One person hosts, everyone else joins with the invite.

Hosting

Press F2 and create a room on this server. You become the owner.

/collab host my-jam

Mint an invite as a join code plus a passphrase. Read the code out, send the passphrase on a different channel (a second message, a call, across the room).

/collab invite --code

Full owner guide: hosting a room.

Joining

Paste what the host sent you. For an invite link, press F2 and type:

/collab join https://bakery.andrath.nl/j/…

For a join code, type the code, then the passphrase when asked:

/collab join bakery.andrath.nl K7QF-92XM-PD4T

Always check the consent prompt — host, room, owner fingerprint. Details: joining a room.

What to expect in a room

  • Everyone hears every accepted evaluation at the same shared instant, about a third of a second after someone presses F5 — like a local Alt+Enter, but synchronized.
  • Typing is shared live, including typos. Sound only changes when someone evaluates.
  • Your own slots stay yours. Slot 0 is the shared scratch pad. F7 shows who is here, F9 lists the slots.
  • If your connection drops, the music keeps playing and your edits queue up; you resync when you are back. See connection troubles.
