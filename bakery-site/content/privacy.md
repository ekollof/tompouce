---
title: "Privacy"
description: "No accounts, minimal logs, ciphertext only."
---
- **No accounts.** No usernames, passwords, or email addresses exist on this server. Access is by capability: the invite link or the join code plus passphrase.
- **Content is ciphertext.** Code, text, names, chat and sample lists are sealed with the room key, which the server never holds.
- **Metadata is minimal.** The server necessarily learns opaque room and member ids, roles, connection counts, message sizes and timing. Operational logs keep no room ids at info level and no keys, codes, or names. IP addresses are masked to /24 (IPv4) or /56 (IPv6) and kept for at most 7 days.
- **No analytics.** No trackers, no third-party code on these pages.
- **You can hide further.** Nothing stops you reaching this instance over a VPN or Tor.
